# Pixel Lightning Cam Device Checklist

## Installation

- Install the current GitHub Actions APK artifact.
- Grant camera permission.
- Confirm the rear-camera preview appears and status becomes `Armé · analyse native active`.

## Controlled first test

- Put the Pixel on a stable support in a dark room.
- Use another display for a short lightning clip; avoid filling the whole field with the display.
- Confirm a narrow bolt triggers within one visible frame without repeated captures for the same flash.
- Confirm the JPEG opens from `Pictures/LightningCam`.
- Confirm the MP4 opens from `Movies/LightningCam` and has a duration greater than zero.

## Outdoor storm test

- Keep the phone sheltered and powered; do not expose it or the operator to lightning risk.
- Frame mostly sky with a small amount of stable horizon.
- Record missed bolts, false triggers, approximate delay, focus quality, grain, and clipping.
- Compare automatic focus against the distant scene before arming.

## Feedback to capture

- Pixel model and Android build.
- Approximate scene darkness and whether street lights are visible.
- Number of visible bolts, detected events, and false events.
- Example photo and matching video when possible.
- Whether the photo is sharp, saturated, noisy, or late.
